# SID_PromptGenerator Design (4.2.1)

## Node Interface

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                         SID_PromptGenerator                                          │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  INPUTS (3 dot connectors only)                                                    │
│  ├── image (IMAGE) ─────────────────── Required                                    │
│  ├── llm_model (LLM_MODEL) ─────────── Optional (dot connector)                   │
│  └── user_prompt (STRING) ──────────── Optional (dot connector, NOT text box)     │
│                                                                                     │
│  OUTPUTS (2)                                                                        │
│  ├── prompt (STRING) ───────────────── Final prompt for image generation          │
│  └── prompt_metadata (STRING/JSON) ─── Detailed JSON of all captured information  │
│                                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

## Mode Specifications

### 1. OVERRIDE MODE (user_prompt provided)

```
INPUT:  user_prompt = "A beautiful woman in red dress"
OUTPUT:
  prompt = "A beautiful woman in red dress"
  prompt_metadata = {
    "mode": "override",
    "source": "user_prompt",
    "processing": "none",
    "taggers_executed": false,
    "llm_executed": false,
    "florence_executed": false
  }
```

### 2. FLORENCE MODE (no llm_model, no user_prompt)

```
EXECUTION:
  1. Load Florence VLM (PromptGen v2.0)
  2. Run MORE_DETAILED_CAPTION
  3. Output florence_description as prompt

OUTPUT:
  prompt = "{florence_description}"
  prompt_metadata = {
    "mode": "florence",
    "source": "florence_description",
    "model": "MiaoshouAI/Florence-2-large-PromptGen-v2.0",
    "taggers_executed": false,
    "llm_executed": false,
    "florence_executed": true,
    "florence_output": "{raw florence output}"
  }
```

### 3. QUICK MODE (llm_model provided, analysis_mode=Quick)

```
EXECUTION:
  1. NO taggers executed
  2. Single-shot detailed prompt to LLM (Local or API)
  3. LLM describes image directly

LLM PROMPT:
  "Describe this image in detail for AI image generation.
   Include: subject, appearance, clothing, pose, environment,
   lighting, composition. Write as flowing natural sentences."

OUTPUT:
  prompt = "{llm_output}"
  prompt_metadata = {
    "mode": "quick",
    "source": "llm_single_shot",
    "llm_provider": "anthropic|openai|local|...",
    "llm_model": "claude-sonnet-4-20250514",
    "taggers_executed": false,
    "llm_executed": true,
    "llm_passes": 1,
    "florence_executed": false
  }
```

### 4. STANDARD MODE (llm_model provided, analysis_mode=Standard)

```
EXECUTION:
  1. Execute 22 taggers/analyzers
  2. Tags used to CHERRY-PICK prompt questions (not in prompt)
  3. Build template prompt based on detected content
  4. Single LLM call with template prompt

TAGS → DECISIONS:
  WD14: "1girl" → subject_type=WOMAN → ask about appearance
  NudeNet: suggestive → ask about body details
  Shot Type: MS → ask about pose (body visible)
  Places365: studio → skip environment detail questions

TEMPLATE PROMPT (built from decisions):
  "Describe this woman in detail:
   - Her appearance (ethnicity, hair color/style, eye color, face, skin)
   - Her clothing (style, color, fabric, fit, accessories)
   - Her pose and expression
   - The lighting and mood
   Write as a single flowing paragraph for image generation."

OUTPUT:
  prompt = "{llm_output}"
  prompt_metadata = {
    "mode": "standard",
    "source": "llm_template",
    "llm_provider": "local",
    "llm_model": "Qwen3-VL-4B",
    "taggers_executed": true,
    "llm_executed": true,
    "llm_passes": 1,
    "florence_executed": false,
    "decisions": {
      "subject_type": "WOMAN",
      "gender": "female",
      "nsfw_level": "SUGGESTIVE",
      "shot_type": "MS",
      "scene_type": "STUDIO",
      "template_sections": ["appearance", "clothing", "pose", "lighting"]
    },
    "taggers": {
      "wd14": {"1girl": 0.98, "long hair": 0.92, "dress": 0.88, ...},
      "pixai": {...},
      "nudenet": {...},
      "shot_type": {"MS": 0.82},
      "places365": {"studio": 0.75},
      ...
    }
  }
```

### 5. DETAILED MODE (llm_model with supports_reasoning=True, analysis_mode=Detailed)

```
REQUIREMENTS:
  - llm_model.supports_reasoning == True
  - Typically: Claude, GPT-4, Gemini (not local models)

EXECUTION:
  1. Execute 22 taggers/analyzers
  2. Tags cherry-pick which components to analyze
  3. LLM executed in 2-3 passes (component-by-component)

PASSES:
  Pass 1: Subject + Appearance
  Pass 2: Clothing + Pose + Environment
  Pass 3: Lighting + Composition + Final assembly

OUTPUT:
  prompt = "{assembled_from_passes}"
  prompt_metadata = {
    "mode": "detailed",
    "source": "llm_multi_pass",
    "llm_provider": "anthropic",
    "llm_model": "claude-sonnet-4-20250514",
    "taggers_executed": true,
    "llm_executed": true,
    "llm_passes": 3,
    "florence_executed": false,
    "decisions": {...},
    "taggers": {...},
    "pass_outputs": {
      "pass_1": "{subject + appearance description}",
      "pass_2": "{clothing + pose + environment}",
      "pass_3": "{lighting + composition + final}"
    }
  }
```

### 6. EXTREME MODE (llm_model with supports_reasoning=True, analysis_mode=Extreme)

```
REQUIREMENTS:
  - llm_model.supports_reasoning == True
  - Maximum detail extraction

EXECUTION:
  1. Execute 22 taggers/analyzers
  2. Tags cherry-pick ALL possible components
  3. LLM executed in MANY passes (one per component)

PASSES (example for WOMAN subject):
  Pass 1: Subject identification
  Pass 2: Ethnicity analysis
  Pass 3: Hair description
  Pass 4: Face description
  Pass 5: Eyes description
  Pass 6: Body/Figure description
  Pass 7: Clothing description
  Pass 8: Accessories description
  Pass 9: Pose description
  Pass 10: Expression description
  Pass 11: Environment description
  Pass 12: Lighting description
  Pass 13: Composition/Framing
  Pass 14: Final assembly

OUTPUT:
  prompt = "{maximum_detail_assembled}"
  prompt_metadata = {
    "mode": "extreme",
    "source": "llm_extreme_multi_pass",
    "llm_provider": "anthropic",
    "llm_model": "claude-sonnet-4-20250514",
    "taggers_executed": true,
    "llm_executed": true,
    "llm_passes": 14,
    "florence_executed": false,
    "decisions": {...},
    "taggers": {...},
    "component_outputs": {
      "subject": "...",
      "ethnicity": "...",
      "hair": "...",
      "face": "...",
      "eyes": "...",
      "body": "...",
      "clothing": "...",
      "accessories": "...",
      "pose": "...",
      "expression": "...",
      "environment": "...",
      "lighting": "...",
      "composition": "..."
    }
  }
```

## Prompt Library (Tag-Based Templates)

Templates are selected based on detected tags. Tags are NEVER included in the final prompt.

### Subject Detection → Template Selection

```yaml

  # WOMAN SUBJECT
  # =========================================================================
  woman:
    trigger_tags: ["1girl", "woman", "female", "lady"]

    base_prompt: |
      Describe this woman in detail for AI image generation.

    sections:
      appearance:
        trigger: always
        prompt: |
          Describe her appearance: ethnicity, age impression,
          hair (color, length, style), eye color, facial features,
          skin tone and texture.

      clothing:
        trigger_tags: ["dress", "shirt", "outfit", "wearing", "clothed"]
```

## Node Implementation Sketch

```python
class SID_PromptGenerator:
    CATEGORY = "SID Nodes"
    RETURN_TYPES = ("STRING", "STRING")
    RETURN_NAMES = ("prompt", "prompt_metadata")
    FUNCTION = "generate"

    @classmethod
    def INPUT_TYPES(cls):
        return {
            "required": {
                "image": ("IMAGE",),
            },
            "optional": {
                "llm_model": ("LLM_MODEL",),      # Dot connector
                "user_prompt": ("STRING",),       # Dot connector (not text box)
                "analysis_mode": (["Quick", "Standard", "Detailed", "Extreme"],),
            },
        }

    def generate(self, image, llm_model=None, user_prompt=None, analysis_mode="Standard"):
        metadata = {}

        # Priority 1: Override mode
        if user_prompt is not None and user_prompt.strip():
            return (user_prompt, json.dumps({
                "mode": "override",
                "source": "user_prompt",
                "processing": {"taggers_executed": False, "llm_executed": False}
            }))

        # Priority 2: Florence mode (no LLM)
        if llm_model is None:
            prompt, florence_meta = self._execute_florence(image)
            return (prompt, json.dumps({
                "mode": "florence",
                "source": "florence_description",
                **florence_meta
            }))

        # Priority 3: LLM modes
        if analysis_mode == "Quick":
            return self._execute_quick(image, llm_model)
        elif analysis_mode == "Standard":
            return self._execute_standard(image, llm_model)
        elif analysis_mode == "Detailed":
            return self._execute_detailed(image, llm_model)
        elif analysis_mode == "Extreme":
            return self._execute_extreme(image, llm_model)
```
